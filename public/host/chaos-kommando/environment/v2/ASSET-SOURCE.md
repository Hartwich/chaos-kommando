# Coastal arena art

Original assets generated with OpenAI's built-in image generation tool on 2026-10-02 for Chaos-Kommando. No third-party game sprites or textures were used.

- `coastal-background.png`: painterly cartoon tropical coast; calm blue sky, distant teal islands, turquoise ocean; no foreground terrain, characters, UI, or text.
- `sandstone.png`: flat tileable golden sandstone strata; chunky ochre blocks, warm crevices, subtle fossils; no landscape silhouette or UI.

The foreground silhouette, grass fringe, collision, destruction, particles, labels, and HUD are rendered from live game state. Existing original marshmallow rig assets remain in use with new animation choreography.
