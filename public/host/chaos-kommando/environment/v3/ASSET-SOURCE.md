# Coastal foliage sprites

Created for Chaos-Kommando with the built-in image generation tool on 2026-10-27. Original generated game artwork, transparent PNG exports; no third-party game art was supplied. The files preserve their alpha channel. Runtime alpha-bound measurement compensates for export margins; collision and blast masking remain procedural.
